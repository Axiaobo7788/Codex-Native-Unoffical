# Calibrated Architecture Adoption Matrix & Evidence Reconciliation

> **Baseline Audited**: `Codex-Native-Unoffical` `HEAD` (`17f08f3`) vs ChatGPT Desktop (`26.326.51703` / `codex-cli 0.167.0-alpha.3.2`)
> **Governing ADR**: `ADR-032` (superseding and recalibrating `ADR-031`)

---

## 1. Adoption Classification Taxonomy

Every design decision in this matrix uses one of six explicit adoption categories:

1. **`ADOPT_PATTERN`** — Adopt the structural pattern or state model, implemented idiomatic to Flutter/Dart/Rust.
2. **`ADAPT_NATIVE`** — Adapt the concept to native Flutter Sliver / Rust `codex-native-host` characteristics rather than copying Electron/React magic numbers.
3. **`COPY_MEASURED_BEHAVIOR`** — Match measured visual tokens, layout proportions, keyboard shortcuts, and interaction polish.
4. **`KEEP_OUR_ADVANTAGE`** — Preserve areas where `Codex-Native-Unoffical` (`HEAD`) is already cleaner, safer, or higher-performance than Electron.
5. **`DO_NOT_ADOPT`** — Reject Electron/Node runtime coupling, system-prompt copying (`AGENTS.md` Rule #1), direct SQLite mutation of `~/.codex/*`, or private `/backend-api/*` / `/wham/*` dependencies in core.
6. **`RESEARCH_MORE`** — Defer commitment where behavior depends on undocumented cloud gates or uninspected mobile clients.

## 3. Concrete Code-Review & Architectural Debt Items (`16.A–16.E` — Implemented & Verified)

All five concrete items identified in the `17f08f3` / `99e6141` `HEAD` audit have been implemented, unit/widget regression-tested, and live-walkthrough verified in the **Desktop Shared Conversation Foundation Hardening** phase:

1. **[Debt 16.A — Cross-Thread Scroll Anchor Restoration (RESOLVED)]** ([`lib/src/app/presentation/conversation.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/app/presentation/conversation.dart), [`test/app/bounded_timeline_test.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/test/app/bounded_timeline_test.dart)):
   - **Problem**: `_threadScrollOffsets` stored `threadId -> raw pixel offset (double)`, while `HistoryController.bindThread(threadId)` cleared `_turns` and fetched only the newest page (`turnPageSize = 20`). Switching away from a thread where `>1` page of older turns was loaded and switching back clamped `-4000 px` onto the wrong turn.
   - **Implemented Fix (`ADAPT_NATIVE`)**: Replaced raw pixel offsets with `_ThreadScrollBookmark(scrollPixels, anchorItemKey, anchorTurnId, anchorViewportTopDy)` (`max 32` threads). On thread return, `_scheduleThreadScrollRestore` pages older turns on demand (up to `_maxRestorePages = 5` / `100` turns) until `anchorTurnId` is present, then aligns `anchorItemKey` to its exact `anchorViewportTopDy` (`0.0 px` drift in live walkthrough Stage 5 and across viewport width resizes in `bounded_timeline_test.dart`).
2. **[Debt 16.B — `maxRetainedTurns = 100` Eviction Edge in `HistoryController.loadOlderTurns()` (RESOLVED)]** ([`lib/src/features/conversation/history_controller.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/features/conversation/history_controller.dart), [`lib/src/app/presentation/conversation.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/app/presentation/conversation.dart)):
   - **Problem**: When `loadOlderTurns()` appended older turns past `maxRetainedTurns = 100`, `_turns.removeRange(0, evictedTurnCount)` removed the newest turns at `reverseIndex 0..k-1`, shifting the reverse index of every older turn and causing `SliverMultiBoxAdaptorElement` to rebind mounted children to different items and jump the viewport.
   - **Implemented Fix (`ADAPT_NATIVE`)**: Added `loadOlderVersion`, `evictionVersion`, and `lastEvictedItemIds` to `HistoryController`, wired `findChildIndexCallback` into `_ConversationScrollView`'s `SliverList.builder` (`ValueKey('measured-$itemKey')`) so mounted `RenderBox`es preserve element identity across index shifts, widened `_averageMeasuredItemHeight` clamp to `4096.0 px`, and aligned the pre-load visible anchor after rebuild (`0.0 px` drift across `285,523 px` 100-turn real thread in Stage 3).
3. **[Debt 16.C — Domain Layer Circular Import (RESOLVED)]** ([`lib/src/domain/user_message_presentation.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/domain/user_message_presentation.dart), [`lib/src/domain/history_models.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/domain/history_models.dart), [`lib/src/domain/thread_models.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/domain/thread_models.dart)):
   - **Problem**: `history_models.dart` imported `thread_models.dart` while `thread_models.dart` imported `history_models.dart`.
   - **Implemented Fix (`KEEP_OUR_ADVANTAGE`)**: Extracted `UserAttachmentKind`, `UserMessageAttachment`, `UserMessagePresentation`, and `parseUserMessagePresentation` into leaf module `lib/src/domain/user_message_presentation.dart` with zero `domain/` imports, eliminating all circular dependencies in `lib/src/domain/`.
4. **[Debt 16.D — `_RenderConversationViewport` Custom RenderObject Audit (RESOLVED)]** ([`lib/src/app/presentation/conversation.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/app/presentation/conversation.dart), [`test/app/bounded_timeline_test.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/test/app/bounded_timeline_test.dart)):
   - **Problem**: `_RenderConversationViewport` shifts `child.parentData.paintOffset` upward in `performLayout()` when `totalExtent < size.height` so short conversations top-align inside an `anchor: 1.0` viewport.
   - **Implemented Fix (`ADAPT_NATIVE`)**: Audited Flutter's `RenderViewportBase` (`packages/flutter/lib/src/rendering/viewport.dart`), confirming `paintOffset` is the authoritative transform used by `paint`, `hitTestChildren`, `applyPaintTransform`, `describeSemanticsConfiguration`, and `showOnScreen`, and added widget regression tests covering pointer hit-testing, semantics bounds, focus `Scrollable.ensureVisible`, and dynamic short-to-overflow resize transitions.
5. **[Debt 16.E — User Envelope Heuristic Precedence & Deduplication (RESOLVED)]** ([`lib/src/domain/user_message_presentation.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/domain/user_message_presentation.dart), [`lib/src/protocol/history_protocol.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/lib/src/protocol/history_protocol.dart), [`test/protocol/history_protocol_test.dart`](file:///home/axiaobo/%E6%96%87%E6%A1%A3/flutter%20projects/Codex-Native-Unoffical/test/protocol/history_protocol_test.dart)):
   - **Problem**: `parseUserMessagePresentation` needed strict structured `UserInput` precedence, semantic deduplication against legacy text envelopes, bounded scanning, and adversarial tests.
   - **Implemented Fix (`ADAPT_NATIVE`)**: Enforced structured `UserInput` precedence (`localImage`, `image`, `skill`, `mention`) with semantic deduplication against legacy `# Files pasted by the user:` / `# Files mentioned by the user:` / `# Context from my IDE setup:` envelopes, bounded scanning (`maxEnvelopeScanChars = 32768`, `maxUserMessageAttachments = 16`, `maxAttachmentFieldChars = 240`), and adversarial tests for spoofed mid-body headers, malformed envelopes, and duplicate attachments.
