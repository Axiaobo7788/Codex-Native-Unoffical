## Supported contract

Public stable `0.167.2` and installed `0.167.0-alpha.3.2` expose top-level
model/provider/approval/sandbox settings in Start/Resume/Fork replies. Stable
`thread/settings/updated` carries `threadSettings`, using `effort` and
`sandboxPolicy` where session replies use `reasoningEffort` and `sandbox`.
The public release was rechecked against the official release API during this
verification; it remained `rust-v0.167.2`. Generated schemas, not a catalog
recommendation, define the projection.

Native retains bounded identifiers and policy classifications, not raw config
or writable-root lists. Granular approval, external sandbox and unknown values
remain distinct from nullable writable overrides. At most 100 small snapshots
and invalidation records are retained. Adapter generation and local observation
order fence notifications, admitted requests and retired contexts; they are
not a stock revision. A scalar eviction watermark conservatively returns
unknown instead of resurrecting an older response after its superseding
snapshot has been evicted. Unload/archive/delete invalidate values. Metadata
selection of a cold thread does not resume it. See ADR-062.
