## 2. `U9` ↔ `F-file-diff` Metadata & Lazy-Preview Contract Checklist

To bind `CodexFileChangeActivityList` cleanly into `conversation.dart` once `Root`'s `F-file-diff` slice lands (without presentation touching `OutputProtocolAdapter` or transport internals):

1. **Ordered per-file metadata + cap count on live & saved `fileChange` entries:**
   - Per-file list (`changes[]`, bounded by `maxFilesPerItem`) exposing `path`, `kind` (`add` | `delete` | `update` | `unknown`), optional `movePath`, kind-aware `additions` / `deletions`, `hasUnifiedHunkHeader` (`isUnifiedDiff` — critical because stock `codex app-server` `kind: add` / `delete` bodies can be raw unprefixed content where leading Markdown `- bullet` lines must render as additions on `add`, matching `ac47002`), plus `totalFileChangeCount` when `changes.length` was capped.
2. **Item execution status propagation (`CodexFileChangeStatus`):**
   - Preserve live & saved item status (`inProgress`, `completed`/`applied`, `interrupted`/`unconfirmed` -> `stopped`, `declined`/`failed` -> `rejected`) so per-file rows render `Creating` / `Stopped creating` / `Rejected` / `Created` accurately instead of collapsing non-completed states to `Edited`.
3. **Deterministic 4-state body discrimination (`0` wasted RPCs on empty/oversized):**
   - **`0`-byte diff (`bytes == 0` or inline empty string without descriptor):** map synchronously to `CodexFileDiffBodyState.empty` (`Contents deleted` for `delete`, `No changes` for `add`/`update`) with **`0` `host/output/readRange` calls**.
   - **Oversized diff (`bytes > maxPreviewBytes` if preview is gated vs bounded slice):** either expose `previewTooLarge` (`Diff too large to preview`, keeping `<Verb> <fileName>` on outer row) or load a bounded slice (`ready` + `truncated: true` -> `Showing bounded diff preview`).
   - **Retired / missing descriptor (`withoutSessionReference()` post-restart, `16,384` `SpoolStore` eviction, or uncached direct-stock history):** map truthfully to `CodexFileDiffBodyState.unavailable` (`Diff preview unavailable`) with optional controller-owned retry/re-read hook.
4. **Controller-owned lazy per-file preview loader & bounded active cache:**
   - Triggered only when the user expands `(entryId/itemId, fileIndex/path)`; returns bounded lines + `isUnifiedDiff` + `truncated` while evicting on thread switch, runtime restart, or small LRU bound so inactive/collapsed items retain zero diff-line heap.
