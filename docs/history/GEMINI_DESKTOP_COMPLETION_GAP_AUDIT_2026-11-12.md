## 4. Cross-Cutting Audits: Responsive (`700` / `820` / `1191`+), Keyboard & Disabled/Loading/Error States

### 4.1 Responsive Tiers (`narrow` `700px` / `normal` `820px` / `wide` `1191px` & `1450px`)
1. **`narrow` (`700px`, `< 760px` `_CompactWorkspace`, `app_shell.dart:583, 607–620, 1377–1557`) — `P1` Structural Defect:**
   - Official `25894` transitions at `768px`; Native transitions at `760px`.
   - **Critical source finding:** `_CompactWorkspace` constructs `_ConversationPanel` **without `hasDesktopShell: true`** (`app_shell.dart:607–620`, default `false`). Resizing a desktop window from `820px` down to `700px` **silently flips the conversation, header, activity rows, questions, and composer out of Desktop mode into legacy pre-Desktop R0/mobile UI** (`desktopComposer = false`, legacy focus border, header `Prose | Commands | Execution` segmented control, header folder/token/PR pills, red header `Stop` button, and modal Goal dialog instead of inline strip/editor)!
   - Simultaneously, `< 760px` drops the entire application menu strip (`File`/`Edit`/`View`/`Help`), `Back`/`Forward` buttons, Global Navigation Rail, `Ctrl+B`/`Ctrl+[`/`Ctrl+]` shortcuts, and inline `Customize` workspace (falling back to a modal dialog mislabeled `'Automations & Skills'` in `_ThreadPanel`, `sidebar_activity.dart:189`).
2. **`normal` (`820px`) & standard `wide` (`1191px`) — `Changes` vs `Goal` Split Threshold (`conversation.dart:2138–2140` vs `2182`) — `PARTIAL (evidence open)`:**
   - `Goal` splits beside chat whenever `workspace >= 672px` (`>= ~1012px` window width with `340px` left panel, so `1191×865` splits cleanly).
   - `Changes` (`canSplit`, `conversation.dart:2138–2140`) checks `constraints.maxWidth > 960` on the workspace column with a source comment noting the official resize coordinator (`961657.97fdcc5e7d.js`) switches pane behavior at a `960 px` workspace. Because `1191×865` with a `340px` left panel leaves `851px <= 960px`, opening `Changes` replaces the timeline rather than splitting unless the sidebar is collapsed or window width exceeds `~1300px`. Unequal `Goal` threshold alone does **not** prove official drift; keep `Changes` placement/threshold `PARTIAL (evidence open)` pending matched live official open-pane verification, while mutual exclusivity of `Changes` and `Goal` (`conversation.dart:3502`) remains a separate structural gap (`S12`).
